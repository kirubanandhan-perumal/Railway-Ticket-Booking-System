# Railway Ticket Booking System

A Java-based railway ticket booking application implementing seat allocation, RAC, and waiting-list management.

## Features

* Railway ticket booking
* Seat availability and allocation
* RAC management
* Waiting-list management
* Ticket booking and cancellation
* Object-oriented application design

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Data Structures
* Algorithms

## Project Overview

This project was developed to implement railway ticket booking logic using Java. The application focuses on efficient seat allocation and handling different booking states such as confirmed tickets, RAC, and waiting lists.

## Getting Started

### Prerequisites

* Java Development Kit (JDK)
* Any Java IDE such as Eclipse, IntelliJ IDEA, or VS Code

### Running the Project

1. Clone the repository.
2. Open the project in your preferred Java IDE.
3. Compile the Java source files.
4. Run the main application class.

## Project Structure

The repository contains the Java source code and supporting files required to run the railway booking system.
